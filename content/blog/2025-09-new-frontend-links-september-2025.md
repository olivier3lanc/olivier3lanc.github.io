## Web app

* [How does my Browser Score?](https://browserscore.dev/) Formerly known as The CSS3 Test. The name was no longer accurate, since it has been testing a lot more than CSS 3 for years now, and the new name gives it room to grow beyond just CSS.
* [Spätzi, l'assistant contrastes](https://spatzi.alsacreations.com/) Vérifiez et optimisez le contraste de vos couleurs selon les standards d'accessibilité (WCAG et APCA). Explorez les variations de couleurs en OKLCH pour créer des palettes accessibles. 
* [oklch.fyi](https://oklch.fyi/) Convert, generate OKLCH colors and create a unique color palette for your next app.
* [HDR Gradients](https://gradient.style) Wide gamut Color 4 compliant CSS gradient builder.
* [Frame Zero](https://www.framezero.app/)  Sketch -> Animate -> Share. Create motion in minutes. All in your browser, no sign-up. 

## JavaScript

* [Image Compare Viewer](https://github.com/kylewetton/image-compare-viewer) Compare before and after images, for grading and other retouching for instance. Vanilla JS, zero dependencies.
* [JSON Editor](https://github.com/json-editor/json-editor) JSON Editor takes a JSON Schema and uses it to generate an HTML form. It has full support for JSON Schema version 3 and 4 and can integrate with several popular CSS frameworks (bootstrap, spectre, tailwind). Take a look at this [example](https://json-editor.github.io/json-editor/) for a simple form submission case study.
* [Over Type](https://overtype.dev/) THE MARKDOWN EDITOR THAT'S A TEXTAREA. OverType is a transparent textarea over rendered markdown. Plain text simplicity, WYSIWYG beauty, zero complexity. 
* [Create a Draggable Element in JavaScript](https://www.kirupa.com/html5/drag.htm) A common gesture we use all the time and take for granted is the ability to drag an element around on screen. Despite how common this drag gesture is, there is no good built-in support for making an element draggable on the web. This is doubly-so if we wish to go beyond the mouse and support things like touch! That's where this tutorial comes in. Over the next few sections, we'll look at a pure JavaScript-based solution (aka no jQuery) that will allow you to turn any boring element into one that you can drag around on your page. Onwards!
